# KyrieAuto — 战双帕弥什自动化脚本

基于图像识别的 **战双帕弥什 (Punishing: Gray Raven)** 游戏自动化工具，自动完成日常/周常任务。

## 功能模块

| 模块 | 状态 | 说明 |
|------|:----:|------|
| ✅ **日常任务** | 已完成 | 公会签到、采购补给、宿舍委托、执勤、商店购买、任务领取、仓库血清、拟战、通行证 |
| ✅ **幻痛囚笼** | 已完成 | α/β/γ三组 × 骑士/混沌/地狱，自动配队，每周奖励 |
| ✅ **纷争战区** | 已完成 | 双场战斗 + 自动配队 + 每周奖励 |
| ✅ **矿区** | 已完成 | 4 区域扫荡 + 奖励领取 |
| ✅ **矩阵循生** | 已完成 | 循环战斗，手动中断 |
| ✅ **归途之旅** | 已完成 | 回归活动消息自动发送 |
| ⏸️ **寒境曙光** | 暂停 | 逻辑过于复杂，导航已实现 |

## 使用方式

1. 启动游戏，进入主界面（建议分辨率2560*1600）
2. 运行 `干爆战双帕尼尼.exe`（或 `python src/main.py`）
3. 在 GUI 窗口中选择要执行的任务模块
4. 点击「开始」运行
5. 按 **Alt + E** 随时中断任务

## 技术栈

- **Python 3.13** + **pyautogui**（图像识别自动化）
- **PIL** / **OpenCV**（图像处理）
- **pynput**（键盘监听）
- **tkinter**（GUI 窗口）
- **PyInstaller**（打包为 exe）

## 打包构建

```bash
cd src
python build.py
```

输出在 `src/干爆战双帕尼尼/` 目录下。

## 注意事项

- 游戏必须在前台运行，不可最小化
- 推荐2560*1600分辨率运行
- 每次运行前确保从主菜单开始
