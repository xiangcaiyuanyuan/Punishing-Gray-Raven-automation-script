# KyrieAuto — 战双帕弥什自动化脚本

基于图像识别的 **战双帕弥什 (Punishing: Gray Raven)** 游戏自动化工具，自动完成日常/周常任务。

## 功能模块

| 模块 | 状态 | 说明 |
|------|:----:|------|
| ✅ **日常任务** | 已完成 | 公会签到、采购补给、宿舍委托、执勤、商店购买、任务领取、仓库血清、拟战、通行证 |
| ✅ **幻痛囚笼** | 已完成 | A/B/C三组 × 骑士/混沌/地狱，自动配队，每周奖励 |
| ✅ **纷争战区** | 已完成 | 双场战斗 + 自动配队 + 每周奖励 |
| ✅ **矿区** | 已完成 | 4 区域扫荡 + 奖励领取 |
| ✅ **矩阵循生** | 已完成 | 循环战斗，按 Alt+E 手动中断 |
| ✅ **寒境曙光** | 已完成 | 演绎关卡推进流程 |
| ✅ **归途之旅** | 已完成 | 回归活动消息自动发送 |

## 使用方式

1. 启动游戏，进入主界面
2. 运行 `干爆战双帕尼尼.exe`（或 `python src/main.py`）
3. 在 GUI 窗口中选择要执行的任务模块
4. 点击「开始运行」
5. 按 **Alt + E** 随时中断任务

> 模板截图基于 **2560×1600** 分辨率截取。脚本启动时会自动检测游戏窗口（客户区）分辨率并对模板做等比缩放，因此也支持其它分辨率/窗口模式运行。
> 为获得最稳定的识别效果，**建议使用全屏 2560×1600**（与截图基准一致，无需缩放、识别精度最高）。分辨率低于截图基准时，小图标经缩放后识别可靠性会下降。

## 运行日志

- 程序自动在 **`logs/`** 目录按天生成日志：`kyrie_YYYYMMDD.log`
- 每次启动自动**清理非当天的旧日志**，只保留当天
- 详细错误堆栈请查看 exe 控制台窗口或当日日志文件

## 技术栈

- **Python 3.13** + **pyautogui**（图像识别自动化）
- **PIL** / **numpy**（图像读取与缩放；OpenCV 由 pyautogui 内部使用）
- **pynput**（键盘监听，Alt+E 中断）
- **tkinter**（GUI 窗口）
- **PyInstaller**（打包为 exe）

## 打包构建

```bash
cd src
python build.py
```

构建流程：
1. 自动关闭正在运行的 `干爆战双帕尼尼.exe`
2. 清理旧的 `build/` 临时目录与输出目录中的 `logs/`、`config/`
3. PyInstaller 打包到 `src/干爆战双帕尼尼/`
4. 自动压缩为 `干爆战双帕尼尼.zip`

## 项目结构

```
KyrieAuto/
├── data/imgs/        # 图像识别模板（中文命名，参考分辨率 2560x1600 截取）
├── src/
│   ├── main.py       # 入口：GUI + 任务执行主循环
│   ├── build.py      # PyInstaller 打包脚本
│   ├── core/         # window(GUI) / executor(任务引擎) / task_builder(DSL)
│   ├── tasks/        # 各模块任务定义 + task_modules 注册表
│   └── utils/        # helpers(图像查找/缩放) / logger(日志系统)
├── tests/            # 辅助测试与诊断脚本
└── config/           # 运行进度文件（自动生成，不提交）
```

## 注意事项

- 游戏必须在前台运行，不可最小化（脚本会自动还原最小化的游戏窗口）
- 推荐 **2560×1600** 分辨率运行
- 每次运行前确保从主菜单开始
- 支持中断后从上次进度**断点续跑**（启动时会询问是否继续）
